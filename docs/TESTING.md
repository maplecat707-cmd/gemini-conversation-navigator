# 验证与兼容范围

本文件记录测试能证明的范围，不把本地演示数据当作官方 Gemini 兼容性证据。

## 0.1.2 Android 收录修复

用户真机反馈：侧栏能显示并识别文字，但同一消息被拆成多个目录项，自动向上滚动没到开头便停止。已据此建立回归场景，确认旧版在以下情况失败：消息容器里有多个文字节点、父节点只给出第一段、文字只放在无障碍描述里、容器仅支持向上／向下滚动，以及历史加载用时 4.2 秒。API 28 和 35 上旧代码共触发 10 个失败测试。

修复内容：优先按消息资源容器／列表项边界合并段落；保留不同子节点的文字而不是读到父节点文字就返回；读取非控件文字节点的描述；支持方向滚动动作；收录等待连续 10 秒无进展，利用实际滚动事件辨别长消息中的移动；取消或达到每阶段 600 次滚动／10 分钟的上限后允许继续收录且不丢弃已有条目。

新增测试还覆盖长回复跨屏时文字不变但滚动位置在变、停止后继续收录保留旧条目的 ID，以及复制诊断不包含对话或无障碍描述。消息边界由 App 提供的结构决定，缺乏边界时仍会出现文字片段；不把模拟结构测试当成反馈手机上的修复证明。

本地验证：4 个索引测试，以及 15 个节点／服务场景在 API 28、35 各执行一次，共 34 项全部通过；debug、release 构建通过，Lint 无错误（保留 4 条已有警告）。

### 安装后复测

1. 覆盖安装 0.1.2 APK，确认无障碍服务开启，打开原先出问题的那段对话。
2. 点击「新对话 / 清空」后「收录前文」，观察是否越过旧版停止的位置。
3. 若仍停在中间，等待 Gemini 历史加载完成，再点「继续收录」；检查已读到的较晚条目仍保留。
4. 检查一个多段落提问是否合成一个目录项，并搜索早期文字点击定位。
5. 若仍拆分或漏收，在该屏点击「复制识别诊断（不含对话）」并粘贴反馈，同时说明手机型号和 Gemini 版本。无需提供私人对话。

## 0.1.1 网页兼容修复

访问官方未登录 Gemini 并发送生成的测试提问时，确认 `.query-text` 内含一份隐藏的 `You said` 无障碍标题，标题重复了整个提问。0.1.1 从目录提取副本中去掉这些隐藏标题，保留原网页无障碍节点，同时保留多行提问的分隔。新增回归测试后，本地 9 个浏览器场景全部通过。Android APK 仍为 0.1.0，不变更签名或安装流程。

2026-11-03 14:57–15:11 UTC，在 Linux Chromium 安装扩展并访问**未拦截的官方未登录 Gemini**，发送 20 条生成的测试提问，收到 20 轮真实回复。核对全部目录文字与提问完全一致且顺序正确，搜索第 2 条并点击后原文进入视口，「最新」和「最早提问」均定位成功。[机器验证记录](live-web-evidence.json) · [真实页面截图](live-web-verified.png)。Windows 和 Linux CI 的 9 项浏览器测试也已通过。

该结果证明上述未登录网页与 20 轮会话场景；不代表已登录账号、更多历史的服务端懒加载、全部 Gemini 实验布局或 Android 官方 App 已完成验证。

### 可选的真实网页验证

```bash
# 会向官方 Gemini 发送 20 条生成的测试提问，需要可访问的网络。
# 使用独立的未登录浏览器配置，不读取个人浏览器配置或历史。

```

可设置 `ANCHOR_LIVE_ROUNDS` 为 2 到 20 来调整轮数。脚本实际安装扩展，等待真实回复，检查目录的顺序和完整提问、搜索定位、第一个／最后一个提问的滚动，并将结果与截图写入被 Git 忽略的 `test-results/live-web/`。不会拦截网页请求或注入假对话；网络失败、服务限制、未收到回复都会作为失败记录。此脚本不在日常 CI 中运行，避免持续向服务发送请求。普通 `npm test` 仍使用离线夹具。

## 网页扩展

`npm test` 使用 Playwright，在真实 Chromium 中安装仓库里的 Manifest V3 扩展。浏览器请求的 `https://gemini.google.com/app/...` 被测试夹具拦截，不访问账号。

覆盖场景：

- 多轮长对话的目录提取，点击后滚动正确的嵌套滚动容器。
- 搜索命中、关键词标记、空结果，以及提问中的 HTML 字符串不能执行脚本。
- 同样的提问多次出现、嵌套提问标签、流式文本更新。
- 单页应用切换会话，包括空会话，旧目录和筛选词被清除。
- 通过滚动触发懒加载历史，并恢复原阅读位置。
- 加载中停止、加载中切换会话。
- Escape、窄屏布局、窄屏点击后收起。
- 深色模式、无提问状态；生成 `web-preview.png` 供视觉检查。

已验证 DOM 形式为 `user-query`、`.query-text` 等 Gemini 常见结构。还支持 `[data-message-author-role="user"]` 与 `.user-query-container`。**未使用真实登录账号验证当前在线 Gemini 的所有页面版本。** Canvas、嵌入式页面、共享页及实验版布局没有专门适配。扩展在 Linux 和 Windows Chromium 中测试；Chrome／Edge 使用相同扩展 API，但不等于已在每个浏览器版本上实测。

## Android

构建与测试命令：

```bash
cd android
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

纯 Java 索引测试覆盖历史页重叠合并、顺序、重复文字、搜索、空页和清空。Robolectric 节点测试覆盖滚动容器选择、文本提取、过滤输入框／密码／按钮／隐藏节点、父子重复文本、应用包过滤与 Google 宿主开关。

Robolectric 服务测试驱动实际 `NavigatorService`，使用 10 个模拟无障碍页面，验证收录、返回起点、点击旧内容定位、取消后没有后续滚动、离开 Gemini 清空、目标不存在时停止。

**模拟节点测试不能证明官方 Gemini Android App 当前版本暴露了同样的节点和滚动动作。当前开发环境没有连接 Android 真机，尚未完成官方 App 真机验证。** Android 首版因此为实验性预览，不承诺支持每一款设备／Gemini 版本。

## 真机验收清单

在发布兼容性结论前，请记录手机型号、Android 版本、Gemini 版本、语言，并验证：

1. 安装 APK，打开引导页面；未同意前不读取内容。
2. 同意并启用无障碍服务，打开官方 Gemini 长对话。侧栏只在 Gemini 前台出现。
3. 至少 20 轮对话，从末尾点「收录前文」。目录顺序合理，早期文字确实被收录；无法读取时有明确提示。
4. 搜索前面独特的一段文字，点击后确实回到它在官方 App 中的位置。
5. 定位中点停止、切到其他 App，都不再自动滚动。
6. 回到 Gemini 后重新收录；在 Gemini 内换会话时清空后重新收录。
7. 重复提问、很长的回复、图片附件、加载慢和旋转屏幕，均不会无限滚动或崩溃。
8. 系统设置关闭服务后，悬浮窗消失且不再读取。

Windows 真机验收：按 README 安装扩展，登录 Gemini，使用至少 20 轮长对话验证搜索、回到前文、懒加载、编辑提问、切换会话、页面刷新及 Chrome／Edge 快捷键。
